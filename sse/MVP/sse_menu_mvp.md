## 2. 홈 (Home)

### 목적
로그인 후 첫 화면. 내 현황 + 커뮤니티 동향을 한눈에 파악

### 화면 구성

```
내 주가 카드 (파란 배경)
  현재 주가 / 주간 변동률 / 기록 / 출석률 / 종합 지수 / 보유 코인

핵심 지표 3개 (가로 그리드)
  이번 주 PB | 출석 연속 | 투자 수익

훈련 일지 위젯
  요일별 입력 현황 + 오늘 기록하기 버튼

────────────────────────────
시즌 랭킹          투자자 랭킹
탭: 주가/상승률/   탭: 수익률/발굴
성실도
내 순위 강조       내 순위 강조
────────────────────────────

최근 공시          D-7 대회 카드
최신 3건           출전 선수 + 투자 시간

코인 바
  보유 코인 + 투자하기 버튼
```

### 핵심 포인트
- 시즌 랭킹 / 투자자 랭킹 **동시 노출** — 탭으로 세부 전환
- 내 순위는 항상 **강조 표시** (파란색 / 보라색)
- 대회 카드에 **투자 가능 시간 카운트다운** 표시
- 홈에서 대부분의 핵심 정보 파악 가능

## 3. 수영 지수

### 목적
선수 주가를 결정하는 종합 지수 현황 상세 확인

### 화면 구성

```
상단 탭
  전체 지수 | 현재 실적 | 성장성 | 훈련 투자 | 시장 지위 | 리스크

핵심 지표 4개 (가로 그리드)
  종합 지수 | 현재 기록 | 출석률 | 현재 주가

지수 구성 바 차트
  현재 실적 (30%) ████████░░  75점
  성장성   (25%) ██████░░░░  60점
  훈련 투자 (20%) █████████░  90점
  시장 지위 (15%) ███████░░░  70점
  특별 이벤트(10%) ███░░░░░░░  30점
  리스크 감점      █░░░░░░░░░  -2점

최근 공시 이벤트
  이벤트별 주가 반영 내역

주간 기록 변동
  기록 / 출석 / 안정성 / 주가 변동
```

### 지수 카테고리별 탭 상세

| 탭 | 표시 내용 |
|----|-----------|
| 현재 실적 | 기록 / PB 달성률 / 향상률 / 안정성 |
| 성장성 | 나이 보정 / 세계기록 대비 / 훈련량 / 종목 다양성 |
| 훈련 투자 | 출석률 / 코치 참여 / 일지 성실도 / 전지훈련 |
| 시장 지위 | 연령대 랭킹 / 국제대회 / 인지도 |
| 리스크 | 부상 이력 / 멘탈 안정성 / 훈련 공백 |

## 4. 선수 목록

### 목적
전체 상장 선수 탐색 + 투자 대상 발굴

### 화면 구성

```
상단
  IPO 신청 버튼 (우측 상단)

검색 / 필터
  검색창 | 등급 필터 | 정렬 옵션

탭
  전체 | 상승 | 하락 | 내 투자 | 신규 IPO

요약 지표 4개
  상장 선수 | 주간 상승 | 주간 하락 | PB 달성

선수 테이블
  순위 | 선수 | 등급 | 주가 | 주간 변동 | 기록 | 종합 지수 바 | 투자 버튼
```

### 테이블 컬럼 상세

| 컬럼 | 내용 |
|------|------|
| 순위 | 주가 기준 전체 순위 |
| 선수 | 이름 / 나이 / 특이사항 |
| 등급 | 대형주 / 중형주 / 중소형주 / 스타트업 |
| 주가 | 현재 코인 수치 |
| 주간 변동 | % 변동률 (색상 구분) |
| 기록 | 50m 평영 기록 |
| 종합 지수 | 바 차트 + 점수 |
| 투자 버튼 | 투자하기 / 투자중 (상태 구분) |

### 필터 / 정렬 옵션

```
등급 필터: 전체 / 대형주 / 중형주 / 중소형주 / 스타트업
정렬: 주가 높은순 / 상승률 높은순 / 기록 빠른순 / 지수 높은순
탭: 전체 / 상승 / 하락 / 내 투자 / 신규 IPO
```

## 5. 대회 현황

### 목적
대회 = 실적 발표 시즌. 출전 명단 확인 + 투자 판단 + 결과 확인

### 화면 구성

```
탭
  전체 | 출전 예정 | 진행중 | 결과 완료 | 내 선수 출전

D-7 메인 카드 (임박 대회 강조)
  대회명 / 날짜 / 장소
  출전 선수 명단 (공시 완료)
  투자 가능 시간 표시

대회 카드 그리드 (2열)
  각 카드: 대회명 / 날짜 / 상태 뱃지 / 출전 선수 아바타 / 버튼

최근 결과 공시
  순위 / 선수명 / 기록 / PB 여부 / 주가 변동
```

### 대회 상태 뱃지

| 상태 | 색상 | 버튼 |
|------|------|------|
| 출전 예정 | 파란색 | 투자 준비 |
| 명단 공시 예정 | 주황색 | 알림 설정 |
| 진행중 | 초록색 | 실시간 보기 |
| 결과 완료 | 회색 | 결과 보기 |

### 3단계 이벤트 흐름

```
출전 명단 공시 → 48시간 투자 오픈 → 대회 결과 → 주가 반영
```

## 6. 내 주가

### 목적
나의 선수 주가 상세 현황 + 지수 구성 파악

### 화면 구성

```
프로필 카드
  아바타 / 이름 / 나이·등급·상장 기간
  뱃지: 개근 N주 / PB 달성 / 일지 N일 / 투자자 N명
  현재 주가 + 주간 변동률

주가 추이 차트
  기간 탭: 1개월 / 3개월 / 시즌
  PB 달성 시점 마킹
  라인 차트 + 그라디언트

종합 지수 구성
  6개 카테고리 바 + 가중치 + 기여 점수
  현재 실적 × 30% = N점
  성장성    × 25% = N점
  훈련 투자 × 20% = N점
  시장 지위 × 15% = N점
  특별 이벤트× 10% = N점
  리스크 감점     = -N점

기록 현황 (2열)
  현재 기록 / 향상률 / 안정성 / 세계기록 대비

주가 이벤트 이력
  PB / 대회 / 개근 / 결석 타임라인
```

## 7. 내 포트폴리오

### 목적
내가 투자한 선수들의 수익 현황 + 코인 자산 관리

### 화면 구성

```
총 보유 코인 카드 (파란 배경)
  총 코인 / 투자 중 / 가용 코인
  시즌 통계: 투자 선수 / 총 수익 / 수익률 / 랭킹

핵심 지표 3개
  이번 주 배당 | 분산 투자 보너스 | 스폰서 등급 선수

보유 선수 테이블
  선수 / 투자 등급 / 투자 코인 / 현재 주가 / 수익률 바 / 지분

등급별 분산 현황 (좌)
  대형주 / 중형주 / 중소형주 / 스타트업 / 가용 코인 바

최근 코인 내역 (우)
  배당 / 적립 / 투자 / 보너스 타임라인
```

### 투자 등급별 혜택

| 등급 | 지분 | 혜택 |
|------|------|------|
| 개인투자자 | 1% 미만 | 기본 |
| 서포터 | 5% 이상 | 기록 알림 우선 |
| 스폰서 | 10% 이상 | 사진/영상 우선 공개 |
| 메인스폰서 | 30% 이상 | 용품 자수 + 공식 타이틀 |

## 8. 훈련 일지

### 목적
개인 훈련 기록 + 코인 보너스 + 투자자 소통

### 화면 구성

```
핵심 지표 4개
  이번 달 입력 | 누적 거리 | 평균 강도 | 일지 코인

오늘 훈련 입력 폼
  장소 / 거리(m) / 시간(분) / 훈련 내용 / 강도 / 컨디션
  메모 (투자자에게 공개)
  저장 시 +10 코인 안내

훈련 달력 (월간)
  파란색: 훈련 기록
  초록색: PB 달성
  회색: 미기록
  테두리: 오늘

최근 훈련 기록 (좌)
  날짜 / 강도 뱃지 / 거리·시간·컨디션 / 메모

연속 기록 현황 (우)
  현재 연속 N일
  GitHub 잔디 스타일 훈련 밀도
  보너스 현황: 7일 / 30일 / 100일
```

### 훈련 일지 입력 항목

| 항목 | 선택지 |
|------|--------|
| 장소 | 실내 수영장 / 실외 / 개인 |
| 거리 | 직접 입력 (m) |
| 시간 | 직접 입력 (분) |
| 훈련 내용 | 드릴 / 체력 / 스피드 / 혼합 |
| 강도 | 가볍게 / 보통 / 힘들게 |
| 컨디션 | 1~5점 |
| 메모 | 자유 입력 (투자자 공개) |

### 연속 입력 보너스

| 연속 | 보상 |
|------|------|
| 7일 | +50 코인 |
| 30일 | +300 코인 |
| 100일 | 특별 뱃지 |

## 9. 공시 알림

### 목적
선수 / 대회 / 코인 관련 모든 공시를 한곳에서 확인

### 화면 구성

```
사이드바 알림 뱃지 (읽지 않은 수)

전체 읽음 처리 버튼

핵심 지표 4개
  오늘 공시 | 주가 상승 알림 | 대회 관련 | 이번 주 총 공시

탭
  전체 | 내 주가 | 투자 선수 | 대회 | 코인 | IPO

알림 목록 (날짜별 그룹)
  오늘 / 어제 / 이번 주

알림 설정 카드
  유형별 토글 온/오프
```

### 알림 유형별 색상

| 유형 | 색상 | 예시 |
|------|------|------|
| PB 달성 / 주가 상승 | 초록 | 최○○ PB +30% |
| 대회 공시 | 파란 | 명단 확정 / 결과 |
| 코인 적립 | 주황 | 참가비 / 배당 |
| 신규 IPO | 보라 | 이○○ 신규 상장 |
| 주가 하락 | 빨강 | 무단 결석 -10% |
| 읽은 알림 | 회색 | 처리 완료 |

### 알림 설정 항목

| 항목 | 기본값 |
|------|--------|
| 내 주가 변동 | ON |
| 투자 선수 공시 | ON |
| 대회 명단 공시 | ON |
| 코인 적립 | ON |
| 신규 IPO | OFF |
| 훈련 일지 리마인더 | 오후 9시 |

## 10. 시즌 랭킹

### 목적
시즌 전체 선수 순위 + 부문별 시상 미리보기

### 화면 구성

```
시즌 배너 (파란 배경)
  시즌명 / 기간 / 참여 선수 / 경과 주 / 평영인의 밤 D-day

탭
  주가 랭킹 | 상승률 랭킹 | 투자자 랭킹 | 훈련 성실도 | 대회 성적

시상대 포디움
  1~3위 시각화

내 순위 카드 (강조)
  현재 순위 / 이름 / 지난주 대비 변동

전체 랭킹 테이블
  순위 / 선수 / 주가 / 주간 변동 / PB 횟수 / 순위 변동
  (내 행은 파란 배경 + 강조)

부문별 TOP 3 그리드 (2열)
  상승률 TOP 3
  훈련 성실도 TOP 3
  PB 달성 TOP 3
  투자자 수익률 TOP 3
```

### 평영인의 밤 시상 부문

| 시상 | 기준 | 부상 |
|------|------|------|
| 최고 수익률 투자자 | 코인 수익률 1위 | 용품 패키지 |
| 최대 지분 보유자 | 단일 선수 최대 투자 | 선수와 함께 시상대 |
| 최다 분산 투자자 | 가장 많은 선수 투자 | 촬영 서비스 |
| 주가 상승률 1위 | 연간 기록 향상 최고 | 사진/영상 패키지 |
| 팀 효율 1위 | 출전 선수 1인당 평균 | 팀 단체 촬영 |
| 유망주상 | 신인 주가 상승률 최고 | Medalbank 용품 |
| 안정성상 | 연간 변동계수 최저 | Medalbank 용품 |

## 11. 투자자 랭킹

### 목적
투자 실력을 두 가지 관점으로 평가 — 수익률 + 유망주 발굴 안목

### 화면 구성

```
메인 탭 (강조형)
  수익률 랭킹 | 유망주 발굴 랭킹

────── 수익률 랭킹 탭 ──────

핵심 지표 4개
  내 총 수익 | 평균 수익률 | 최고 수익 선수 | 투자자 순위

시상대 포디움 (1~3위)

내 순위 카드 (파란 강조)

전체 랭킹 테이블
  순위 / 투자자 / 총 수익 / 수익률 / 투자 선수 수 / 순위 변동

내 포트폴리오 수익 내역
  선수별 투자 코인 → 현재 가치 → 수익

────── 유망주 발굴 랭킹 탭 ──────

발굴 지수 설명 카드
  조기성 × 성장률 × 투자 규모

핵심 지표 4개
  발굴 지수 | 조기 투자 선수 | 최고 발굴 선수 | 놓친 유망주

내 순위 카드 (보라 강조)

전체 랭킹 테이블
  순위 / 투자자 / 발굴 지수 / 조기 투자 / 평균 성장률 / 등급

내 발굴 선수 분석
  선수별: 조기성 / 성장률 / 투자 규모 바 차트
```

### 발굴 지수 공식

```
발굴 지수 =
  투자 시점 주가 대비 현재 주가 상승률
  × 조기성 보정 (IPO 당일 = 최고점)
  × 보유 지분 비율
```

### 발굴 등급

| 등급 | 기준 | 명칭 |
|------|------|------|
| 90점 이상 | 최상위 | 전설 |
| 70~89점 | 상위 | 고수 |
| 50~69점 | 중위 | 중급 |
| 50점 미만 | 하위 | 입문 |
