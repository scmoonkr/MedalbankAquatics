## 1. 핵심 컨셉

> **"선수는 종목, 기록은 실적, 훈련은 투자"**
> 실제 훈련/대회 기록이 게임 내 주가를 움직이는 실시간 스포츠 주식시장

- 현실 데이터가 게임을 움직이기 때문에 **"게임을 위해 더 열심히 훈련하는"** 선순환 발생
- 매주 측정 기록 → 매주 주가 뉴스 → 매주 커뮤니티 화제
- 투자자는 **Medalbank에서 보상** 받는 구조 (선수가 직접 배당하지 않음)
- 이번 프로젝트는 **선수 / 기록 / 훈련** 중심으로 운영 (팀 제도는 추후 적용)

## 2. 전체 구조

### 플레이어 구조

| 역할 | 대상 | 동기 |
|------|------|------|
| **선수** (상장 종목) | 아카데미 회원 | 내 기록이 곧 내 주가 |
| **투자자** | 회원 전체 / 가족 / 코치 | 응원하는 선수 기록 오르면 수익 |
| **거래소 운영자** | Medalbank | 충성도 + 데이터 + 매출 |

### 기업 구조 비유

| 현실 | 주식시장 비유 |
|------|--------------|
| 선수 | 상장 기업 |
| 현재 기록 | 현재 매출 |
| 기록 향상 | 매출 성장 |
| 훈련량 | R&D 투자 |
| 대회 출전 | 실적 발표 |
| 대회 PB | 어닝 서프라이즈 |
| 국가대표 선발 | 코스피 200 편입 |
| 부상 | 리콜 / 악재 공시 |
| 도핑 | 상장폐지 |

### 선수 등급

| 등급 | 50m 평영 기준 | IPO 주가 | 성격 |
|------|--------------|----------|------|
| 🥇 대형주 | 35초 이하 | 2,000 코인 | 엘리트 / 안정적 |
| 📈 중형주 | 35~42초 | 1,500 코인 | 상급 |
| 🌱 중소형주 | 42~50초 | 1,000 코인 | 중급 |

> 초급자가 더 싸고 성장 여지가 많음 = **성장주 논리**

## 3. 투자 화폐 — 참가비 코인

### 핵심 원칙

> 돈을 새로 쓰는 게 아니라
> **이미 내는 참가비가 자산이 되는 구조**

### 주간 코인 적립

| 항목 | 코인 | 비고 |
|------|------|------|
| 참가비 납부 (기본) | +100 | 자동 적립 |
| 당일 훈련 출석 | +50 | 자동 적립 |
| 기록 측정 참여 | +30 | 코치 확인 |
| PB 달성 보너스 | +100 | 코치 확인 |
| 훈련 일지 입력 | +10 | 자기 입력 |
| **최대 주간 획득** | **290 코인** | |

### 연간 적립 비교

| 참석 패턴 | 연간 코인 |
|-----------|-----------|
| 52주 개근 + 일지 성실 | 약 9,880 코인 |
| 52주 개근 | 약 9,360 코인 |
| 월 2회 결석 | 약 5,800 코인 |

> 개근자가 결석자보다 **1.6배 자산** 보유

### 장기 회원 보너스

| 기간 | 적립률 보너스 |
|------|--------------|
| 6개월 이상 | +10% |
| 1년 이상 | +20% |

### 결석의 기회비용

```
기존 인식: 이번 주 못 가면 참가비 날림
변경 인식: 이번 주 못 가면 코인도 못 쌓고 투자도 못함
```

> **결석의 기회비용이 2배로 커지는 효과**

## 4. IPO 조건

### 필수 조건 (3가지 모두 충족)

```
✅ 4주 이상 참석
✅ 3회 이상 기록 측정 (코치 계측)
✅ 참가비 정상 납부
```

### IPO 단계

| 단계 | 기간 | 상태 |
|------|------|------|
| 프리시즌 | 1~2주차 | 관찰만 가능 |
| 예비심사 | 3~4주차 | 기록 측정 시작 |
| 상장 대기 | 조건 충족 시 | IPO 신청 가능 |
| 공식 상장 | 월말 이벤트 | 투자 오픈 |

### IPO 주가 산정

```
3회 측정 기록의 평균 → 기준 주가 테이블 적용 → 공개 상장
```

**예시**
```
1회차: 48.0초 / 2회차: 47.5초 / 3회차: 47.0초
평균: 47.5초 → 중급자 → IPO 주가 1,000 코인
```

### 패스트트랙 인센티브

```
4주 만에 조건 충족 → "패스트트랙 상장" 뱃지 + IPO 주가 10% 프리미엄
```

## 5. 수영 선수 지수 — 주가 결정 요소

> 주가 = 현재 실적 + 미래 가치 + 훈련 투자 + 시장 지위 + 특별 이벤트 - 리스크

---

### 5-1. 현재 실적 지표 (30%)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| 매출 | **현재 기록** | 50m 평영 절대 시간 | 35초=100점 / 1초당 -2점 |
| 영업이익률 | **PB 달성률** | 대회 출전 중 PB 횟수 / 총 출전 수 | 100% = 100점 |
| 매출 성장률 | **기록 향상률** | (이전기록 - 현기록) / 이전기록 × 100 | 1% 향상 = +10점 |
| 실적 안정성 | **기록 안정성** | 최근 4주 변동계수 | 1% 미만 = 100점 |

---

### 5-2. 성장성 지표 (25%)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| PER | **나이 보정 지수** | 세계기록 대비 차이 / 나이 | 어릴수록 고배수 |
| 성장 여력 | **세계기록 대비** | (현기록 - 세계기록) / 세계기록 × 100 | 차이 클수록 여지 |
| R&D 투자 | **훈련 투자량** | 주당 훈련 횟수 × 시간(h) | 주 10h = 100점 |
| 파이프라인 | **출전 계획** | 시즌 내 출전 예정 대회 수 | 1대회 = +10점 |
| 신사업 | **영법 다양성** | 보유 영법 수 | 4영법 = 100점 |

---

### 5-3. 훈련 투자 지표 (20%)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| CAPEX | **아카데미 출석률** | 출석 / 전체 회차 × 100 | 100% = 100점 |
| 인적 투자 | **코치 수업 참여** | 코치 지도 훈련 횟수 | 주 3회 = 100점 |
| 자기계발 | **훈련 일지 성실도** | 월간 일지 입력 횟수 | 30일 = 100점 |
| 전략적 투자 | **전지훈련 참가** | 연간 전지훈련 참가 횟수 | 1회 = +20점 |

---

### 5-4. 시장 지위 지표 (15%)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| 시장점유율 | **연령대 랭킹** | 동일 연령대 내 순위 | 1위 = 100점 |
| 글로벌 진출 | **국제대회 출전** | 국제대회 출전 여부 | 출전 = +30점 |
| 브랜드 가치 | **선수 인지도** | 투자자 수 + 팔로워 수 | 누적 반영 |
| 경쟁 우위 | **특기 종목** | 주종목 연령대 1위 여부 | 1위 유지기간 반영 |

---

### 5-5. 특별 이벤트 지표 (10%)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| 코스피 200 편입 | **국가대표 선발** | 선발 여부 | +50점 🚀 |
| 어닝 서프라이즈 | **대회 PB** | 예상 대비 기록 초과 | +30점 |
| 유상증자 | **새 종목 추가** | 신규 영법 대회 출전 | +20점 |
| M&A | **코치 변경** | 상위 코치 영입 | +15점 |
| 특허 | **독보적 기록** | 아카데미 내 1위 | +10점 |

---

### 5-6. 리스크 지표 (감점)

| 주식 요소 | 수영 지표 | 수치화 방법 | 산정 기준 |
|-----------|-----------|------------|-----------|
| 부채비율 | **부상 이력** | 최근 1년 부상 횟수 | 1회당 -10점 |
| 오너 리스크 | **멘탈 안정성** | 대회 vs 훈련 기록 차이 | 차이 클수록 감점 |
| 유동성 위험 | **훈련 공백** | 연속 결석 주수 | 1주당 -5점 |
| 감사 의견 | **도핑 이력** | 클린 여부 | 위반 시 상장폐지 |

---

### 5-7. 최종 수영 선수 지수 공식

```
선수 지수 (100점 만점)

= 현재 실적   × 30%
+ 성장성      × 25%
+ 훈련 투자   × 20%
+ 시장 지위   × 15%
+ 특별 이벤트 × 10%
- 리스크 감점
```

### 5-8. 실제 선수 비교 예시

**김○○ / 25세 / 50m 평영 38초**
```
현재 실적   75점 × 30% = 22.5
성장성      60점 × 25% = 15.0  ← 나이 때문에 할인
훈련 투자   90점 × 20% = 18.0  ← 개근 + 일지 성실
시장 지위   70점 × 15% = 10.5
특별 이벤트 30점 × 10% =  3.0
리스크 감점               -2.0  ← 부상 이력 1회
────────────────────────────────
총점: 67점 → 주가 1,340 코인
```

**이○○ / 15세 / 50m 평영 40초**
```
현재 실적   65점 × 30% = 19.5
성장성      95점 × 25% = 23.75 ← 나이 프리미엄
훈련 투자   80점 × 20% = 16.0
시장 지위   60점 × 15% =  9.0
특별 이벤트 20점 × 10% =  2.0
리스크 감점               0
────────────────────────────────
총점: 70.25점 → 주가 1,405 코인
```

> 기록은 김○○이 더 좋지만
> **나이 프리미엄으로 이○○의 주가가 더 높음**
> 완전히 주식시장의 성장주 논리와 동일

## 6. 선수 주가 공식

### 주간 변동 구조

```
주간 주가 변동률 =
  기록점수   (50%)
+ 출석점수   (20%)
+ 안정성점수 (20%)
+ 이벤트     (10%)
```

### 6-1. 기록점수 (±최대 20%)

```
향상률 = (이전 기록 - 이번 기록) / 이전 기록 × 100
```

| 기록 변화 | 주가 변동 |
|-----------|-----------|
| 2% 이상 향상 | +20% 🚀 |
| 1~2% 향상 | +10% 📈 |
| 0.5~1% 향상 | +5% 📈 |
| 0.3초 이내 유지 | +2% ➡️ |
| 0.5~1% 하락 | -5% 📉 |
| 1% 이상 하락 | -10% 📉 |

> 하락보다 상승 폭이 큰 이유 = **도전 장려**

### 6-2. 출석점수 (±최대 10%)

| 출석 상태 | 주가 변동 |
|-----------|-----------|
| 출석 + 기록 측정 완료 | +5% |
| 출석했지만 측정 미참여 | +1% |
| 사전 공지 결석 | -3% |
| 무단 결석 | -10% |

```
3주 연속 출석 보너스 → 추가 +3%
```

### 6-3. 안정성점수 (±최대 10%)

```
변동계수 = 표준편차 / 평균기록 × 100  (최근 4주 기준)
```

| 변동계수 | 의미 | 주가 |
|----------|------|------|
| 1% 미만 | 매우 안정 | +10% |
| 1~2% | 안정적 | +5% |
| 2~4% | 보통 | 0% |
| 4% 이상 | 불안정 | -5% |

### 6-4. 이벤트 보너스

| 이벤트 | 주가 변동 |
|--------|-----------|
| 🏆 국가대표 선발 | +50% |
| 🥇 대회 PB 달성 | +30% |
| 🏅 대회 입상 | +20% |
| 🏊 대회 출전 완주 | +10% |
| 📅 전지훈련 참가 | +5% |
| 🤕 부상 공시 | -20% |
| 💊 회복 복귀 | +10% |

### 주가 하한선 (안전장치)

```
IPO 기준가의 30% 이하로는 절대 하락 불가
포기 방지 장치 — 바닥까지 떨어진 선수도 복귀 가능
```

## 7. 훈련 일지 시스템

### 데이터 2트랙 구조

| 구분 | 공식 트랙 | 비공식 트랙 |
|------|-----------|------------|
| 데이터 | 코치 측정 기록 / 대회 기록 / 출석 | 본인 입력 훈련 일지 |
| 검증 | 코치 / 공식 계측 | 자기 신고 |
| 주가 반영 | ✅ 반영 | ❌ 미반영 |
| 활용 | 주가 산정 | 콘텐츠 / 투자 참고 |

> 조작해도 주가에 영향 없음 → 조작할 이유 없음
> **오히려 더 진솔한 데이터가 쌓임**

### 훈련 일지 입력 항목

```
오늘 훈련 내용
──────────────
📍 장소        실내 / 실외 / 개인
🏊 거리        몇 m 수영했나
⏱️ 시간        몇 분 훈련했나
💪 강도        가볍게 / 보통 / 힘들게
📋 내용        드릴 / 체력 / 스피드
😊 컨디션      1~5점
📌 메모        자유 기록
```

### 훈련 일지 활용

```
훈련 일지 꾸준히 입력
        ↓
성실도 뱃지 부여        ← 게임 요소
        ↓
투자자에게 공개         ← 응원 / 관심 유도
        ↓
잡지 콘텐츠 소재        ← Medalbank 활용
        ↓
대회 전 컨디션 참고     ← 투자 판단 보조 지표
```

### 훈련 일지 연속 입력 보너스

## 10. 배당 구조

### 배당 공식

```
배당 = 보유 코인 × 선수 주가 상승률 × 대주주 보정 계수
```

**예시**
```
김○○ 선수 이번 주 +20% 상승
내 보유 코인 500 / 지분 15% (스폰서 등급)

배당 = 500 × 20% × 1.5 = 150 코인 추가 획득
```

### 코인 사용처

| 사용처 | 내용 |
|--------|------|
| Medalbank 용품 할인 | 코인 → 할인 쿠폰 전환 |
| 커스텀 자수 서비스 | 코인으로 결제 |
| 사진 / 촬영 서비스 | 코인으로 결제 |
| 재투자 | 다른 선수에게 투자 |
