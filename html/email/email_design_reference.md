## 레이아웃 구조

- 전체 컨테이너 너비: **600px** (고정)
- 좌우 내부 패딩: **48px**
- 배경색: `#EDEFF2` (외부), `#FFFFFF` (카드)
- 카드 border-radius: **8px**
- 카드 shadow: `0 2px 12px rgba(0,0,0,0.08)`

### 섹션 순서
1. **헤더** — 다크 네이비 + 그라데이션 라인 (4px)
2. **제목 + 부제 + 발신 계기 박스** — 좌측 파란 세로선 박스
3. **동의 효과 1·2·3** — 번호 뱃지 리스트
4. **CTA 버튼** — 단독 중앙 배치 + 빨간 주의 문구
5. **개인정보 수집·이용 동의** — 표 형식
6. **본인 확인 및 허위 동의 경고** — 앰버 배경 경고 박스
7. **동의 철회** — 소형 텍스트 + 텍스트 링크
8. **푸터** — 연회색 배경, 브랜드 정보

## 톤앤매너 원칙

1. **기업적·전문적** — 과도한 감성 표현 없이 명확하고 간결하게
2. **계층적 강조** — 중요한 정보는 색상(네이비/블루)과 굵기로 차별화, 법적 경고는 앰버로 시각적 분리
3. **위화감 없는 경고** — 법적 내용은 별도 박스로 분리하되 공격적이지 않은 톤 유지
4. **즉각성 명시** — 버튼 클릭의 법적 효력을 버튼 바로 아래에 빨간 텍스트로 명확히 고지
5. **정보 밀도 조절** — 법적 필수 항목은 표/박스로 압축, 본문은 여백을 넉넉히

## 동의 대상 사진 목록 섹션 (썸네일 갤러리)

**위치:** 동의 효과(1·2·3번) 섹션 바로 아래, CTA 버튼 바로 위

**목적:** 어떤 사진에 동의했는지 법적 증거 역할 + 수신자가 확인 후 버튼 클릭하는 자연스러운 흐름

### 구성
- 섹션 제목: `동의 대상 사진 목록` (13px, bold, #0D1F3C)
- 안내 문구: `아래 사진들에 대해 공개 요청 및 사용 동의가 진행됩니다. 내용을 확인한 후 동의 버튼을 눌러주세요.` (11.5px, #9AA3B0)
- 총 사진 수 뱃지: 파란 텍스트 (#1A6FC4), 연회색 배경 (#F4F7FC), 테두리 (#E0E6EF), border-radius 20px
- 그리드: **4열**, 썸네일 크기 116×116px, 셀 간격 4px, border-radius 4px
- 썸네일 플레이스홀더 배경: #E8ECF1 (이미지 로드 실패 시 fallback)
- 사진 번호: 썸네일 하단 중앙, 10px, #9AA3B0, bold (`#001`, `#002` 형식)
- 1~100장 전부 표시 (동적 생성)

### 템플릿 변수 (백엔드 연동)
- `{PHOTO_COUNT}` → 총 사진 수 (정수)
- `{PHOTO_001_THUMB_URL}`, `{PHOTO_002_THUMB_URL}` ... → 각 사진 썸네일 URL
